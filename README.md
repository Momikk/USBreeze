# USBreeze

[English](README.en.md)

简单直观的 USB 测速工具，查看 U 盘、移动硬盘和移动 SSD 的读写速度。

## 下载

[下载 Windows 版](https://github.com/Momikk/USBreeze/releases/latest)

支持 Windows 10 / 11（64 位），无需安装。

## 怎么用

1. 下载压缩包，完整解压后打开 `USBreeze.exe`。
2. 插入设备，在列表中选中它。
3. 点击「开始测速」，查看读写速度。

先用「快速」测一下；想观察更长时间的表现，可选「标准」或「深入」。测试可随时停止，也可以查看最近记录、导出结果。

## 语言

支持简体中文和 English，默认跟随系统语言；不支持的语言显示英文。点击右上角的语言按钮即可切换，选择会自动保存。

## 测试前了解一下

测试不会覆盖原有文件，测试文件会在完成或停止后自动清理。

速度受电脑接口、线材和设备共同影响。比较线材时，请使用同一设备、接口和测试模式。
