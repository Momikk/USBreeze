# USBreeze

[简体中文](README.md)

A simple USB speed tester for USB flash drives, external hard drives, and portable SSDs.

## Download

[Download for Windows](https://github.com/Momikk/USBreeze/releases/latest)

Works on Windows 10 / 11 (64-bit). No installation needed.

## How to use

1. Download the `.exe` file and double-click to open it. No extraction needed.
2. Connect your drive and select it from the list.
3. Click **Start test** to see its read and write speeds.

Use **Quick** for an initial check, **Large file** for one 1 GiB file, or **Many small files** for 1,024 small files. See speed and elapsed time, stop at any time, view recent results, and export them.

## Language

Simplified Chinese and English are supported. The app follows your system language and uses English if that language is not supported. Use the language button at the top right to switch; your choice is saved automatically.

## Before you test

Tests do not overwrite your existing files. Test files are removed automatically when a test finishes or is stopped.

Speed depends on your computer's port, cable, and drive. When comparing cables, use the same drive, port, and test mode.
